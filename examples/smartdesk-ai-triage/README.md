# SmartDesk AI Triage & Auto-Resolve

This example shows Evals Coach turning a product PRD into an eval for an AI support agent that can classify tickets, call internal tools, reply to customers, and close selected tickets.

It is a useful test of the methodology because a good eval must cover more than response quality. It must also define when the agent may act, when it must hand off to a human, which tools and permissions are allowed, what gets recorded in the audit trail, and how the system should fail safely.
